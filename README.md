# AIML Project and Labs

This repository contains all the labs and projects for the AIML Training Program.

## Guidelines Followed
- Notebook Uploads: The Colab notebook shared after each lecture will be uploaded to this repository.
- Notebook Naming: Notebooks will be named consistently with the ones provided.
- Task Handling: Tasks or assignments are solved directly within the Colab notebook.
- No-Task Notebooks: Notebooks without tasks are uploaded as-is.
- Independent Experimentation: Creative ideas and additional experiments are included.
